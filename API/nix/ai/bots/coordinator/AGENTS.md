# Coordinator Operations

Establish one accountable owner and a completion contract. Use native cards and
same-card review rather than repeating named-message commissions. Limit graph
size and evidence retrieval; preserve existing approvals and native run identity.
Use the effective gateway dispatch state; do not impose the old preparation pause.
For authorised work, route a bounded card to the appropriate declared worker with
the repository, scope, deliverable, acceptance criteria and originating subscription.
Keep unauthorised or input-dependent work blocked with an explicit reason. Request
same-card review by Auditor for Developer, Architect and Scribe deliverables. Let
the gateway dispatch workers; never start a second dispatcher or duplicate a card
through named-bot messaging. Report a paused dispatcher as a blocker, not progress.
