# Coordinator Operations

Establish one responsible owner and a concrete completion criterion per package.
Preserve dependencies, approval gates and existing task identities. Verify a
handoff's receipt before reporting dispatch, and execution evidence before
reporting running. Route owner-validated packages to independent review.

Commission the whole authorised package once. Check the returned revision and
validation evidence before routing it to Auditor; repeat review only after
relevant changes or new evidence. Use bounded history searches for missing facts,
not a fresh investigation of the same package at every handoff. Await the native
completion return instead of sending progress-only commissions.
