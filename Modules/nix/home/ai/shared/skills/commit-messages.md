# Commit messages

- **Subject line:** Use the imperative mood ("Add feature" not "Added feature"), maximum 72 characters, no trailing period.
- **Body:** Focus on _why_ the change was made and the context, rather than summarising what the diff shows.
- **Granularity:** Keep commits atomic (one logical change per commit).
- **Security:** Never commit secrets, tokens, private keys, or generated credentials.
